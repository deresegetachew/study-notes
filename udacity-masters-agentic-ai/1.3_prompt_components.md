# Topic 1.3: Prompt Components

> Module: Agentic AI · Date: 2026-08-27

**Q: What are the five core components of a prompt?**
Role, Task, Output Format, Examples, Context.

**Q: What does each component do?**
- **Role** — persona the model should adopt (e.g., "Act like a pirate!")
- **Task** — the actual instruction/question (e.g., "Perform the calculation: 1 + 1?")
- **Output Format** — how the answer should be structured (e.g., "Output a sentence in Markdown.")
- **Examples** — sample input/output pairs to anchor style and correctness (e.g., "Q: 1 + 3? / A: Tis *4*, yar!")
- **Context** — background info the model needs but wasn't asked to produce (e.g., domain facts, prior conversation, constraints)

**Remember:** a well-formed prompt is these components stacked in sequence — Role sets the lens, Task says what to do, Output Format says how to say it, Examples show what "correct" looks like, Context fills in what the model can't infer on its own.
