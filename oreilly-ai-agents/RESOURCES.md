# AI Agents Resources

## Knowledge

- [Course Slides Level 1–4](./resources/AI_Agents_Course_Slides/) — Primary course material covering agents from fundamentals to production. Level 1: core concepts. Level 2: tools + memory. Level 3: advanced patterns (RAG, reflection, human-in-the-loop). Level 4: multi-agent, scaling, cost.
- [Course Supplemental Notebooks](./resources/AI_Agents_Course_Supplemental_Content/) — Jupyter notebooks for each lesson. Python/LangGraph-based — use for concepts and translate to Node.js for implementation.
- [Anthropic Claude API Docs](https://docs.anthropic.com) — Primary reference for tool use, streaming, and message API. Use when implementing with Claude.
- [Vercel AI SDK Docs](https://sdk.vercel.ai/docs) — TypeScript-first SDK for building AI applications in Node.js. Best choice for NestJS integration. Covers tool use, streaming, structured output.
- [LangChain.js Docs](https://js.langchain.com/docs/) — JS port of LangChain. Use when you need the JS equivalent of the Python examples in the course notebooks.

## Wisdom (Communities)

- [r/LangChain](https://reddit.com/r/LangChain) — Active community. Use for: architecture questions, debugging agent loops, comparing framework choices.
