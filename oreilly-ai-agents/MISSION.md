# Mission: AI Agents for Full Stack Engineers

## Why

Build real, working AI agents in Node.js/NestJS to ground practical experience, open new career opportunities, and upgrade the quality of solutions delivered as a full stack engineer. The goal is shipped code, not theory.

## Success looks like

- Can explain what an agent is and when to use one vs a simpler LLM call
- Has built at least 2-3 working agents in Node.js/TypeScript from scratch
- Understands tool use, memory, and multi-agent patterns well enough to apply them in a NestJS backend
- Can evaluate agent quality and debug when things go wrong
- Comfortable discussing agent architecture in interviews or with a team

## Constraints

- 2 weeks (starting 2026-06-14)
- Node.js / TypeScript is the implementation language — Python examples from course materials must be translated
- NestJS is the preferred backend framework
- Existing course materials (Levels 1–4 PDFs + Jupyter notebooks) are available as a knowledge base

## Out of scope

- Deep Python/LangGraph implementation (use for concepts only)
- Fine-tuning / model training
- Production deployment and scaling (Level 4 territory — revisit after core skills land)
